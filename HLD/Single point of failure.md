Single point of failure means that a single point causes whole architecture failure upon its failure.

It means the architecture is not resilient to begin with.

# Method to fix the single point of failure

- More nodes for server
- Master slave architecture in database
- multiple load balancer/Gateway
- Regions and multiple region in case of whole system failing
